# Dashboard Review
- [ ] Most important task and metric are immediately clear.
- [ ] Data is real or clearly identified as sample data.
- [ ] Tables are used where comparison or scanning matters.
- [ ] Charts have labels, units, context and meaningful scales.
- [ ] Filters and controls have clear state and behavior.
- [ ] Empty, loading, stale and error states are designed.
- [ ] Density supports frequent use without visual clutter.
- [ ] Responsive behavior preserves access to important data.
