# SaaS Application Review
- [ ] Primary workflows are easy to discover.
- [ ] Navigation and information architecture scale to the product.
- [ ] Forms have labels, validation and useful errors.
- [ ] Permissions and destructive actions are clear.
- [ ] Feedback confirms meaningful state changes.
- [ ] Empty, loading, error and success states exist.
- [ ] Component variants are consistent.
- [ ] Keyboard and mobile use are supported.
