# Visual Reference Guide

These original teaching sheets are included in `assets/`.

## 01 — Hero comparison
`assets/01-hero-comparison.png`
Shows a generic centered AI/SaaS hero next to a product-led composition with a concrete promise and evidence. The point is not that centered heroes are forbidden; the point is to make the hero specific.

## 02 — Layout comparison
`assets/02-layout-comparison.png`
Contrasts repeated feature cards with a content-led layout. Cards are useful when they group related information; they are not mandatory containers.

## 03 — Typography comparison
`assets/03-typography-comparison.png`
Contrasts decorative type effects with a more deliberate typographic hierarchy. The right type choice depends on brand and reading context.

## 04 — Motion comparison
`assets/04-motion-comparison.png`
Contrasts decorative animation with clear feedback for a real state change.

Use these images as discussion and critique aids, not as templates to copy. Do not reproduce the example palette or layout automatically.
