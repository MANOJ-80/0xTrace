# Project response style

For every user-facing natural-language response in this repository, including interim updates and final answers, read and apply `.agents/skills/human-prose/SKILL.md` as a final prose pass. Use it by default without waiting for an explicit skill invocation.

Apply the pass only to assistant-authored response prose. Do not rewrite source code, code comments, commands, structured data, quoted source text, exact-output content, or project files unless the user asks for prose editing.
